Flat-colour hatched rectangles, no third-party input, no creative content, generated locally by
a script in this repo with no network call. They exist because `scripts/ui_atlas.gd` `preload()`s
these seven paths and a failed preload is a parse-time error in Godot - without them the script
does not compile and the game does not run at all.

Each region the code slices is filled in its own colour and outlined, so running the game shows
immediately whether every `Rect2` lands where the code expects. Sizes come from
`game/tools/asset-spec.mjs`, which derives them from the `Rect2` calls themselves.

**These are scaffolding. Replace them with real art from the asset pipeline and record that art
here in the proper table above.**
